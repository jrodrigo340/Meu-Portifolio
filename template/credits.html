Credits

All the code on this site was written for this project. The repositories below are where you can study and look up the techniques used here: light and dark themes, scroll animations, accessibility and page transitions. Check each repository's license before reusing code.

  • mdn/content

    The open documentation behind MDN Web Docs, with HTML, CSS and JavaScript explained through examples.

    Where it shows up on this site: Semantic HTML, CSS variables (the themes), IntersectionObserver, localStorage and prefers-color-scheme.

    View on GitHub

  • mdn/dom-examples

    Code examples that accompany the documentation of browser APIs (DOM and Web APIs).

    Where it shows up on this site: The base of main.js: events, the DOM and matchMedia (automatic theme and reduced motion).

    View on GitHub

  • a11yproject/a11yproject.com

    The A11Y Project: practical guides to web accessibility.

    Where it shows up on this site: Visible focus, field labels, color contrast, the skip-to-content link and respect for reduced motion.

    View on GitHub

  • WICG/view-transitions

    Proposal and explainers for the View Transitions API, maintained by the WICG community.

    Where it shows up on this site: The smooth transition between pages (@view-transition in the CSS).

    View on GitHub

  • thedaviddias/Front-End-Checklist

    A checklist to review a front-end site before publishing it.

    Where it shows up on this site: The final pre-launch checklist: SEO, performance, accessibility and good practices.

    View on GitHub
