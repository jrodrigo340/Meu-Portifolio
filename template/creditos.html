Créditos

Todo o código deste site foi escrito para este projeto. Os repositórios abaixo são o lugar para estudar e consultar as técnicas usadas aqui: temas claro e escuro, animações ao rolar, acessibilidade e transição entre páginas. Confira a licença de cada repositório antes de reutilizar código.

  • mdn/content

    A documentação aberta do MDN Web Docs, com HTML, CSS e JavaScript explicados e com exemplos.

    Onde aparece neste site: HTML semântico, variáveis CSS (os temas), IntersectionObserver, localStorage e prefers-color-scheme.

    Ver no GitHub

  • mdn/dom-examples

    Exemplos de código que acompanham a documentação das APIs do navegador (DOM e Web APIs).

    Onde aparece neste site: A base do main.js: eventos, DOM e matchMedia (tema automático e movimento reduzido).

    Ver no GitHub

  • a11yproject/a11yproject.com

    O A11Y Project: guias práticos de acessibilidade na web.

    Onde aparece neste site: Foco visível, rótulos nos campos, contraste das cores, link para pular ao conteúdo e respeito a reduzir movimento.

    Ver no GitHub

  • WICG/view-transitions

    Proposta e explicações da API View Transitions, mantidas pela comunidade WICG.

    Onde aparece neste site: A transição suave entre páginas (@view-transition no CSS).

    Ver no GitHub

  • thedaviddias/Front-End-Checklist

    Lista de verificação para revisar um site front-end antes de publicar.

    Onde aparece neste site: O checklist final antes de publicar: SEO, desempenho, acessibilidade e boas práticas.

    Ver no GitHub
